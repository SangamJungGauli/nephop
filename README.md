# NepHOp (नेपहप)

**Nepalese Hyperparameter Optimizer**: a fast optimizer written in Rust,
for Python and PyTorch.

> Status: very early. Not usable yet.

## Try it

    cargo run

## Roadmap

- [ ] Grid search on one variable
- [ ] Random search
- [ ] Trial history and SQLite storage
- [ ] Python bindings
